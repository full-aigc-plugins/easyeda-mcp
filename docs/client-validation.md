## 超时与兼容性

当前主页的 doc.external 返回 BRIDGE_NOT_READY，但同一内置 MCP 的 invoke + sys_Help.help 可发现接口，external.easyedaMcp 可直接调用。
旧后台会话中 getCurrentProjectInfo 挂起，其他读取正常；关闭工具自建会话并重开副本后工程信息正常返回。扩展对该 API 增加 1500ms 期限；只读操作可使用活动图页提供的真实 parentProjectUuid，结果明确 warning 和来源。写入/保存仍要求完整身份，不绕过校验。未声称此项已消除客户端所有超时。

## 数据边界

终端对 Documents 原文件受 TCC 限制，因此使用访达复制官方示例到 .local/readonly-project；未打开、保存或编辑原示例文件。没有原文件哈希验证。
面板示例副本关闭后 SHA-256 不变；快速入门副本在客户端打开、切换图页并读取后 SHA-256 变化。没有调用工程创建、修改、保存 API；不能据此声称副本文件字节完全不变，也尚未确定该文件变化的具体字段。原件与工作副本分离。

未执行真实工程创建、连线、自动布局/布线、保存、DRC、Gerber/BOM/贴片文件导出。接口代码和模拟测试不能代替实际设计/制造验收。CI 尚未运行，没有 Git 提交、推送或发布。
